Welcome to CheckQRVT

Your go-to tool for secure QR code scanning and URL analysis.

CheckQRVT ensures that every link you scan is safe by utilizing VirusTotal's powerful URL scanning service, helping you avoid phishing and malware attacks.

Learn More

Key Features of CheckQRVT:

  • Redirect Analysis: Detects and analyzes any redirects that might occur from the original URL to ensure that the final destination is safe.
  • Integration with VirusTotal: Leverages VirusTotal's extensive database of antivirus engines to provide a comprehensive safety report for scanned URLs.
  • Open Source: Developed as an open-source project, allowing for transparency and contributions from the community to enhance its functionality.
  • Cross-Browser Compatibility: Coming soon...
  • Web-Based Version: Users can also utilize the web-based version of CheckQRVT for manual URL submissions at checkvt.epizy.com.

Technical Implementation

The CheckQRVT tool is built using a combination of web technologies, including HTML, PHP, CURL, JavaScript, Java, Python, and MySQL. Each component plays a crucial role in the overall functionality, from handling URL submissions to interacting with VirusTotal's API for in-depth analysis. By using PHP and CURL for backend processing, CheckQRVT efficiently retrieves HTTP headers and handles URL redirects to provide users with accurate and detailed results.
